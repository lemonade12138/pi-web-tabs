# Pi Web 标签页版（社区魔改）

基于 [pi-web](https://github.com/agegr/pi-web) 官方版（当前同步至 v0.8.11）的**个人增强版**的**个人增强版**，在官方基础上增加了一个浏览器式的**会话标签页条**，其余功能与官方一致。

> 本项目基于 MIT 协议的官方版本修改，原版版权归原作者所有。本仓库改动遵循同一协议。

## 这个版本多了什么

- **会话标签页条**（页面顶部）：像浏览器标签一样管理多个会话
  - 点标签切换会话，位置稳定不乱跳
  - 按住拖动可自定义排列，顺序记忆在本地
  - `×` 关闭只是隐藏标签，**绝不删除会话**，随时能从左侧加回来
  - 会话在后台运行时标签上转圈，跑完变成小圆点提醒（点开看过自动消失）
  - 双击标签可重命名，文件夹徽章显示会话所属项目
- 关闭了开发模式调试气泡，界面更干净

## 怎么安装（Windows）

### 前提

1. **Node.js** 18 或更高：去 [nodejs.org](https://nodejs.org) 下载 LTS 版，一路下一步
2. **pi 本体**：本网页是 pi 编码助手的界面，需要本机已安装并配置好 pi（含 API key）。没装的话先看 pi 的官方文档

### 三步启动

1. 下载本仓库代码（绿色 Code 按钮 → Download ZIP，解压）
2. 双击 **`双击我启动.bat`**
3. 第一次会自动下载依赖（几分钟），完成后自动打开浏览器 `http://127.0.0.1:30142`，**并在桌面自动创建 Pi Web Tabs 快捷方式**（带图标，以后双击它即可，无黑窗口）

之后每次使用都是双击同一个文件：已经在跑就直接开浏览器，没跑就先启动。

### 想局域网其他设备访问？

命令行进入本目录执行 `npm run dev:lan`，其他设备访问 `http://你的电脑IP:30141`

## 常见问题

- **双击 bat 一闪而过**：多半是没装 Node.js，先装 Node 再来
- **依赖下载失败**：网络问题，重新双击再试
- **端口被占**：关掉旧的命令行窗口，或改 `install-and-start.ps1` 里的 `$port`

## 和官方版的关系

官方更新后，本仓库会尽量跟进（改动集中在 `components/WorktreeSessionTabs.tsx`、`components/AppShell.tsx` 局部、`app/globals.css` 末尾、`next.config.ts`、启动脚本，均有注释标记）。

## 桌面版（实验性）

不想开浏览器？仓库新增 Tauri 桌面壳（`desktop/` 目录），双击图标即得原生窗口：

- **安装包不到 1MB**，壳内存占用约 30MB
- 双击自动检测 30142 端口：网页版在跑就直接连；没跑就用本机 Node 自动拉起，关窗自动清理
- **拖文件进窗口**：Windows 原生拖拽，聊天框直接插入 `@完整文件路径`（浏览器做不到的事）
- 找不到安装目录时，把路径写入 `%APPDATA%\pi-web-desktop\config.json`（`{"installDir":"C:\...\pi-web-custom"}`）后重启即可

安装前提：网页版已安装且完成过一次构建（`npm run build`）+ Node 在 PATH 中。安装包在本仓库 Release 页（`Pi Web_1.1.0_x64-setup.exe`），便携版直接运行 zip 内 exe。

注意：exe 未做代码签名，Windows Defender 首次运行可能提示，选择"仍要运行"即可；智能体本体（pi CLI + 各家密钥）仍需单独安装配置。
